# 周期表ホーム

周期表をタップして学べる Android ホームアプリ（ランチャー）。

- 周期表を指でなぞると拡大表示が追従（セルごとに振動）。離した元素の詳細を表示
- 詳細：原子量・価電子・電気陰性度・第一イオン化エネルギー・融点・沸点・電子殻の図・電子配置・入試ポイント
- 色分け切替：分類 / 電気陰性度 / イオン化エネルギー / 常温の状態。分類と状態は凡例を押して絞り込み
- クイズ：記号と番号を隠した表で位置当て。ミスした元素ほど多く出題（1〜20番 / 入試頻出 / 全118 / 炎色反応）
- 今日の元素（日替わり）、語呂と炎色反応の暗記カード
- アプリ一覧はハニカム格子＋魚眼レンズ。なぞると指の周りが拡大し、離したアプリが起動
  - よく使うアプリほど親指に近い下中央（並びは 1 日単位で固定）
  - ドックから上スワイプし、指を離さずそのままアプリまで滑らせて起動（一筆書き）
  - 検索すると該当アプリだけが親指側に並び直す。長押しでドック追加・アプリ情報・アンインストール
- 縦画面・横画面の両対応（横は左に周期表、右に詳細、右端に縦ドック）
- GPU シェーダー（AGSL, Android 13 以降）: 炎色反応の炎、s/p/d/f 軌道の電子雲、背景のエネルギー場と衝撃波
- 立体の原子模型（電子が周回、ドラッグで回転）、タップ点から表を伝わる波、端末の傾きで表が傾き光沢が流れる
- アプリ一覧の背後を実際にぼかす（Android 12 以降）
- 壁紙が透ける全画面表示、Android 12 以降は端末のテーマ色に連動
- 23時〜5時は表を暗くし就寝を促す
- 分類は新課程準拠（12族＝遷移元素、2族＝アルカリ土類、18族＝貴ガス）

## インストール
`dist/shucey-home.apk` を端末に入れてインストール → ホームボタン → 「周期表ホーム」を常に使う。

## ビルド
```
./gradlew :app:assembleRelease   # Android SDK 34 が必要
./gradlew :app:testReleaseUnitTest  # Robolectric でスクショ（app/build/shots）
```
元素データは `tools/gen_elements.py` で
[Periodic-Table-JSON](https://github.com/Bowserinator/Periodic-Table-JSON)（Wikipedia 由来, CC-BY-SA）から生成。
